A photograph taken while a visit was open is accepted however late its bytes arrive.

`media.declare` names a `storedObjectId` only the server issues, so the command cannot be formed
without signal. A technician working offline queues `survey.submit` first — which completes the
visit — and the declaration arrives behind it on the first bar of signal, where it was refused.
The bytes were already in storage, attached to nothing; the device kept the local file for ever;
and the parcel showed a photograph nobody could open.

The rule now compares the **shutter** rather than the delivery: taken before the visit completed,
accepted; taken afterwards, still refused, which is what the rule was protecting.
